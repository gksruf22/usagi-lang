# Usagi-lang grammar

## 1. 개요
- 이 문서는 우사기랭(UsagiLang)의 문법을 정의한다.
- 현재 구현 범위
  - 1단계(최소 동작. 메인 블록, 정수, 곱하기, 출력문, 주석)
  - 2단계(변수와 연산): 변수, 대입, 정수 입력, 더하기/빼기/곱하기/나누기/나머지
- 단계가 진행될 때마다 규칙을 추가한다. 변경 내용은 `CHANGELOG.md`에 기록한다.

## 2. 규칙

1. 프로그램은 `미야아아`로 시작하는 메인 블록 하나로 이루어지고, `야하핫`으로 끝난다.
2. 한 줄에는 문장 하나만 쓸 수 있다.
3. 사용할 수 있는 문장
    - `야하 식`: 식의 값을 숫자로 출력하고 줄을 바꾼다.
    - `야핫 식`: 식의 값을 숫자로 출력하고 줄을 바꾸지 않는다.
    - `루루루루루 식`: 식의 값을 유니코드 번호로 보고 그 글자를 출력한다. 줄을 바꾸지 않는다.
    - `변수 흐응 식`: 식의 값을 변수에 넣는다. (2단계)
    - `쥬르리 변수`: 정수 하나를 입력받아 변수에 넣는다 (2단계)
4. 정수 표기법
    - 양수: `우` 뒤에 `라`를 붙인다. `라`의 개수가 값을 나타낸다. (`우라` = 1, `우라라라` = 3)
    - 0: `우`만 쓴다. (`라`가 0개)
    - 음수: `우` 뒤에 `루`를 붙인다. `루`의 개수에 마이너스를 붙인 값이다. (`우루` = -1, `우루루루` = -3)
5. 변수 표기법
    - `푸` 뒤에 `루`를 1개 이상 붙인다. `루`의 개수가 변수의 번호이다.(`푸루` = 1번 변수, `푸루루` = 2번 변수)
    - 변수는 선언하지 않는다. 처음 값을 넣을 때 생긴다.
    - 값을 넣은 적 없는 변수를 읽으면 에러다.
6. 연산
    - 곱하기: 공백으로 띄워 쓴다. (우라라 우라라라 = 2 × 3 = 6)
    - 나누기: 붙여 쓴다. (우라라라우라라 = 3 / 2 = 1)
    - 나머지: 핫 (우라라라 핫 우라라 = 3 % 2 = 1)
    - 더하기: 이야 (우라라라 이야 우라라 = 3 + 2 = 5)
    - 빼기: 음수를 곱해서 더한다. (우라라라 이야 우루 우라라 = 3 + (-1 × 2) = 1)
7. 계산 순서
    - 곱하기/나누기/나머지를 먼저, 더하기를 나중에 계산한다.
    - 같은 순서끼리는 왼쪽부터 계산한다.
    - 괄호는 사용할 수 없다. 먼저 계산하고 싶은 부분은 변수에 먼저 넣는다.
8. 나누기와 나머지는 C언어와 같다.
    - 몫은 0 쪽으로 버린다. (-7 / 2 = -3)
    - 나머지의 부호는 왼쪽 수를 따른다. (-7 % 2 = -1)
    - 0으로 나누거나 0으로 나머지를 구하면 에러다.
9. 줄의 맨 앞(들여쓰기 제외)이 `푸루야우라우라`로 시작하면 그 줄 전체가 주석이다.
10. 빈 줄과 들여쓰기는 무시한다.

## 3. EBNF

주석 줄과 빈 줄은 lexer가 미리 지우기에 아래 규칙에는 나타나지 않는다.
`줄끝`은 lexer가 줄이 끝날 때마다 넣는 토큰이다.
`나누기`는 lexer가 붙여 쓴 단어를 자른 자리마다 넣는 토큰이다. (아래 "단어 규칙" 참고)

### 문장 규칙 (토큰 단위)

```
프로그램     = 메인블록 ;

메인블록     = "미야아아" , 줄끝 ,
               { 문장 , 줄끝 } ,
               "야하핫" , [ 줄끝 ] ;

문장         = 출력문 | 붙여출력문 | 문자출력문 | 대입문 | 입력문;

출력문       = "야하" , 식 ;
붙여출력문   = "야핫" , 식 ;
문자출력문   = "루루루루루" , 식 ;
대입문       = 변수 , "흐응" , 식 ;
입력문       = "쥬르리" , 변수 ;

식           = 항 , { "이야" , 항 } ;                  (* 더하기 *)
항           = 값 , { [ 나누기 | "핫" ] , 값 } ;       (* 아무것도 없으면 곱하기 *)
값           = 정수 | 변수 ;
```

### 단어 규칙 (글자 단위, lexer가 처리)

```
정수         = 양의정수 | 음의정수 ;
양의정수     = "우" , { "라" } ;          (* "우"만 있으면 0 *)
음의정수     = "우" , "루" , { "루" } ;   (* "루"가 1개 이상 *)
변수         = "푸" , "루" , { "루" } ;   (* "루"가 1개 이상 *)

붙여쓴단어   = 조각 , 조각 , { 조각 } ;   (* 공백 없이 붙임. 조각 사이마다 나누기 *)
조각         = 정수 | 변수 ;
```

붙여 쓴 단어는 `우`나 `푸`가 나올 때마다 잘라서 조각으로 나눈다.

```
우라라라우라라      →  [우라라라] [우라라]          →  3 / 2
푸루루푸루          →  [푸루루] [푸루]              →  2번 변수 / 1번 변수
우라라라라우라라우라  →  [우라라라라] [우라라] [우라]  →  (4 / 2) / 1
```

### 값과 동작

| 규칙 | 값 / 동작 |
| --- | --- |
| 양의정수 | `라`의 개수 |
| 음의정수 | -(`루`의 개수) |
| 변수 | 그 번호의 변수에 들어 있는 값 |
| 항 | 값들을 왼쪽부터 곱하기·나누기·나머지 한 값 |
| 식 | 항들을 왼쪽부터 더한 값 |
| 출력문 | 식의 값을 10진수로 출력 + 줄바꿈 |
| 붙여출력문 | 식의 값을 10진수로 출력 (줄바꿈 없음) |
| 문자출력문 | 식의 값에 해당하는 유니코드 글자를 출력 (줄바꿈 없음) |
| 대입문 | 식의 값을 변수에 넣음 |
| 입력문 | 한 줄을 읽어 정수로 바꾼 값을 변수에 넣음 |

계산 순서 예시

```
우라라라 우라라라라라우라라 이야 우라
→ ((3 × 5) / 2) + 1
→ (15 / 2) + 1
→ 7 + 1
→ 8
```

## 4. 추가 규칙

### 줄과 공백
- 한 줄에 문장 하나. 문장 하나를 여러 줄에 나눠 쓸 수 없다.
- 토큰과 토큰 사이는 공백(스페이스 또는 탭) 1개 이상으로 구분한다.
- 줄 앞뒤의 공백(들여쓰기)은 무시한다. 들여쓰기는 보기 좋게 하기 위한 것일 뿐 의미가 없다.
- 빈 줄은 어디에 있어도 무시한다.
- **주의**: 공백이 있으면 곱하기, 없으면 나누기다. 공백 하나를 빠뜨리면 에러 없이 다른 값이 나오므로 헷갈린다면 `--tokens` 옵션으로 확인한다.
```
  우라라라 우라라    →  3 × 2 = 6
  우라라라우라라     →  3 / 2 = 1
```

### 주석
- 들여쓰기를 뺀 줄의 맨 앞이 `푸루야우라우라`로 시작하면 그 줄 전체가 주석이다.
- 줄 중간에서 시작하는 주석은 없다.
- 주석의 내용은 정규화하지 않고 그대로 둔다.

### 토큰 판별
- 단어는 아래 순서로 판별한다.
  1. 키워드 표에 있으면 키워드
  2. 정수 규칙에 맞으면 정수
  3. 변수 규칙에 맞으면 변수
  4. `우`·`푸` 앞에서 잘랐을 때 모든 조각이 정수나 변수면 붙여 쓴 단어 (나누기)
  5. 모두 아니면 에러
- 키워드는 정확히 일치해야 한다. 예를 들어 `루루루루`(4개)나 `루루루루루루`(6개)는 문자 출력 키워드가 아니다.
- 키워드 표를 먼저 확인하기 때문에 `우`나 `푸`로 시작하는 키워드(`푸루야우라우라` 등)는 붙여 쓴 단어로 잘리지 않는다.
- 여러 키워드에 맞을 수 있으면 **가장 긴 것**을 고른다.
- `우라루`처럼 `라`와 `루`가 섞인 단어는 정수가 아니다. (에러)
- `푸`만 있는 조각은 변수가 아니다. (에러)
- `이야`, `핫`, `흐응`은 반드시 공백으로 띄워 쓴다. `우라핫우라`처럼 붙여 쓰면 에러다.

### 변수와 대입
- 대입문의 왼쪽에는 변수 하나만 올 수 있다. `푸루우라 흐응 우라`처럼 붙여 쓴 단어는 안 된다.
- 변수 번호에 정해진 한계는 없다.

### 정수 입력
- `쥬르리 변수`는 입력에서 한 줄을 읽는다.
- 앞뒤 공백을 지운 뒤 10진 정수로 바꾼다. 앞에 `-`가 있으면 음수다. (예: `42`, `-7`)
- 정수가 아니면 에러다.
- 더 읽을 입력이 없으면 에러다.

### 파일과 표기
- 소스 파일은 UTF-8로 읽는다. 맨 앞의 BOM은 무시한다.
- 소스(주석 제외)는 읽을 때 NFC로 정규화한다.
- 비슷한 기호는 같은 기호로 바꾼다: `ー` → `-`
- 확장자는 `.usagi`를 쓴다.

### 메인 블록
- 메인 블록은 정확히 하나여야 한다.
- 메인 블록 앞뒤에는 빈 줄과 주석만 올 수 있다.

### 문자 코드
- 문자 출력에 쓸 수 있는 값은 1 이상 0x10FFFF(1,114,111) 이하다.
- 0xD800 ~ 0xDFFF(55,296 ~ 57,343, 서로게이트 영역)는 쓸 수 없다.

### 에러

- 기본적으로 모든 에러는 `하아?` 로만 나타낸다.
- `--unusagi` 옵션: `하아?` 대신 줄 번호와 사람 말 설명을 출력한다.
- 에러는 표준 에러(stderr)로 출력하고 종료 코드 1로 끝낸다.

출력 예시
```
$ python -m usagi 예제.usagi
하아?

$ python -m usagi --unusagi 예제.usagi
[3번째 줄] 알 수 없는 단어: 우라루
```

## 5. 예시

### 글자 출력: "Hi"
H = 72 = 8 × 9, i = 105 = 3 × 5 × 7, 줄바꿈 = 10 = 2 × 5

```
미야아아
  푸루야우라우라 H 출력
  루루루루루 우라라라라라라라라 우라라라라라라라라라
  푸루야우라우라 i 출력
  루루루루루 우라라라 우라라라라라 우라라라라라라라
  푸루야우라우라 줄바꿈
  루루루루루 우라라 우라라라라라
야하핫
```

출력
```
Hi
```

### 숫자 출력
```
미야아아
  야하 우라라 우라라라
  야하 우루 우라라라
  야하 우
  야핫 우라
  야핫 우라라
야하핫
```

출력
```
6
-3
0
12
```

### 연산
```
미야아아
  푸루야우라우라 ((3 × 5) / 2) + 1 = 8
  야하 우라라라 우라라라라라우라라 이야 우라
  푸루야우라우라 5 - 2 = 3
  야하 우라라라라라 이야 우루 우라라
  푸루야우라우라 7 % 3 = 1
  야하 우라라라라라라라 핫 우라라라
  푸루야우라우라 -7 / 2 = -3 (0 쪽으로 버림)
  야하 우루루루루루루루우라라
  푸루야우라우라 -7 % 2 = -1 (왼쪽 수의 부호)
  야하 우루루루루루루루 핫 우라라
야하핫
```
 
출력
```
8
3
1
-3
-1
```
 
### 변수
```
미야아아
  푸루 흐응 우라라라
  푸루루 흐응 푸루 우라라
  야하 푸루루
  푸루루 흐응 푸루루 이야 우루 푸루
  야하 푸루루
  야하 푸루루푸루
야하핫
```
 
출력
```
6
3
1
```
(푸루 = 3 → 푸루루 = 3 × 2 = 6 → 푸루루 = 6 - 3 = 3 → 푸루루 / 푸루 = 3 / 3 = 1)

### 계산기: 입력받은 두 수 더하기

미야아아
  쥬르리 푸루
  쥬르리 푸루루
  야하 푸루 이야 푸루루
야하핫
```
 
입력
```
3
4
```
 
출력
```
7
