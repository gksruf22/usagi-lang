# 우사기랭 (UsagiLang)

> 치이카와 우사기어로 코딩하는 한글 난해 프로그래밍 언어

```
미야아아
  루루루루루 우라라라라라라라라 우라라라라라라라라라
  루루루루루 우라라라 우라라라라라 우라라라라라라라
  루루루루루 우라라 우라라라라라
야하핫
```
```
$ usagi examples/step1/hi.usagi
Hi
```

## 소개

우사기랭은 만화 『치이카와』의 캐릭터 우사기가 내는 소리(팬들이 "우사기어"라고 부르는 `야하`, `우라`, `하아?` 등)를 키워드로 쓰는 프로그래밍 언어입니다. Python으로 만든 인터프리터로 실행합니다.

**설계 원칙**

- **우사기어만 쓴다**: 키워드는 실제 우사기의 말에서 골랐습니다. 단어마다 팬들이 해석한 뜻과 기능을 연결했습니다.
- **늘이기 = 크기**: 우사기가 `우라라라라`처럼 말을 늘이듯, 글자 수가 숫자의 크기가 됩니다. (`우라라라` = 3)
- **우사기는 사람 말을 하지 않는다**: 그래서 기본적으로 에러도 `하아?`로만 출력합니다.

## 설치

**필요한 것**: Python 3.10 이상 (외부 라이브러리 없음)

### 방법 1. GitHub에서 바로 설치

```
pip install git+https://github.com/gksruf22/usagi-lang.git
```

### 방법 2. 저장소를 내려받아 설치

```
git clone https://github.com/gksruf22/usagi-lang.git
cd usagi-lang
pip install .
```

### 방법 3. 설치 없이 실행

저장소 폴더에서 `usagi` 대신 `python -m usagi`를 쓰면 됩니다.

```
python -m usagi examples/step1/hi.usagi
```

> `pip install`이 "externally managed environment" 에러로 막히면, 가상환경(`python -m venv .venv`)을 만들어서 설치하거나 `pipx install git+https://github.com/gksruf22/usagi-lang.git`을 쓰세요.

## 빠른 시작

1. VS Code 같은 코드 편집기로 `hello.usagi` 파일을 만들고, 아래 내용을 넣어 **UTF-8**로 저장합니다.
   (맥의 텍스트 편집기(TextEdit)는 서식 있는 문서로 저장되므로 쓰지 마세요.)

   ```
   미야아아
     야하 우라라 우라라라
   야하핫
   ```

2. 실행합니다.

   ```
   $ usagi hello.usagi
   6
   ```

   `우라라`(2)와 `우라라라`(3)를 띄워 쓰면 곱하기라서 `6`이 출력됩니다.

## 사용법

```
usagi [옵션] 파일.usagi
```

| 옵션 | 설명 |
| --- | --- |
| (없음) | 프로그램을 실행한다 |
| `--unusagi` | 에러가 나면 `하아?` 대신 줄 번호와 사람 말 설명을 보여준다 |
| `--tokens` | 실행하지 않고 렉서가 만든 토큰 목록을 보여준다 (디버깅용) |
| `--ast` | 실행하지 않고 파서가 만든 AST를 보여준다 (디버깅용) |
| `-h`, `--help` | 사용법을 보여준다 |

### 에러

우사기는 사람 말을 하지 않으므로, 모든 에러는 `하아?`로만 나타납니다.
이유가 궁금하면 `--unusagi`를 붙이세요.

```
$ usagi bad.usagi
하아?

$ usagi --unusagi bad.usagi
[2번째 줄] 알 수 없는 단어: 우라루
```

에러는 표준 에러(stderr)로 출력되고, 종료 코드는 1입니다.

## 문법

자세한 규칙과 EBNF는 [docs/grammar.md](docs/grammar.md)에 있습니다.

### 프로그램 구조

프로그램은 `미야아아`로 시작하는 **메인 블록** 하나로 이루어지고, `야하핫`으로 끝납니다. 한 줄에는 문장 하나만 씁니다.

```
미야아아
  (문장들)
야하핫
```

### 키워드

| 키워드 | 기능 | 우사기어 뜻 (팬 해석) | 단계 |
| --- | --- | --- |
| `미야아아` | 메인 블록 시작 | 어서 오세요 | 1 |
| `야하핫` | 블록 끝 | 기세등등 → 다 했다! | 1 |
| `야하 식` | 숫자 출력 + 줄바꿈 | 큰 소리로 외침 | 1 |
| `야핫 식` | 숫자 출력 (줄바꿈 없음) | 짧게 끊어 외침 | 1 |
| `루루루루루 식` | 유니코드 번호를 글자로 출력 (줄바꿈 없음) | 혀 굴리며 소리 내기 | 1 |
| `푸루야우라우라` | 주석 (줄 전체) | 해독 불가 | 1 |
| `푸루…` | 변수 (`루`의 개수가 변수 번호) | 잡초 이름 | 2 |
| `변수 흐응 식` | 대입 | 맞아 (긍정) | 2 |
| `쥬르리 변수` | 정수 입력 | 식욕이 생길 때 → 값을 받아먹음 | 2 |
| `이야` | 더하기 | 흥겨운 감탄사 → 흥이 더해진다 | 2 |
| `핫` | 나머지 | 착지할 때 내는 소리 → 나누고 떨어져 남은 것 | 2 |

### 정수

`우` 뒤에 붙인 글자의 **개수**가 값입니다.

| 표기 | 값 |
| --- | --- |
| `우` | 0 |
| `우라`, `우라라`, `우라라라` … | 1, 2, 3 … (`라`의 개수) |
| `우루`, `우루루`, `우루루루` … | −1, −2, −3 … (`루`의 개수) |

### 곱하기

정수를 공백으로 띄워 쓰면 모두 곱합니다.

```
야하 우라라 우라라라        → 6   (2 × 3)
야하 우루 우라라라          → -3  (−1 × 3)
```

### 변수

`푸` 뒤에 붙인 `루`의 개수가 변수 번호입니다. (`푸루` = 1번, `푸루루` = 2번 …)
`흐응`으로 값을 넣고, `쥬르리`로 키보드에서 정수를 입력받습니다.

```
푸루 흐응 우라라라          → 푸루에 3을 넣는다
쥬르리 푸루루              → 입력받은 정수를 푸루루에 넣는다
야하 푸루 푸루루            → 푸루 × 푸루루 출력
```

값을 넣지 않은 변수를 읽으면 에러입니다.

### 연산

우사기어에는 `+ - × ÷` 같은 기호가 없으므로, **띄어쓰기와 붙여쓰기**로 계산합니다.

| 연산 | 쓰는 법 | 예 | 값 |
| --- | --- | --- | --- |
| 곱하기 | 띄어 쓰기 | `우라라 우라라라` | 6 |
| 나누기 | 붙여 쓰기 | `우라라라라라라라우라라` | 3 (7 / 2) |
| 나머지 | `핫` | `우라라라라라라라 핫 우라라` | 1 |
| 더하기 | `이야` | `우라 이야 우라라` | 3 |
| 빼기 | `우루`를 곱해서 더하기 | `우라라라라라 이야 우루 우라라` | 3 (5 − 2) |

- **계산 순서**: 곱하기·나누기·나머지를 먼저, 더하기를 나중에 계산합니다. 같은 순위끼리는 왼쪽부터 계산합니다.
  (`우라 이야 우라라 우라라라` = 1 + 2 × 3 = 7)
- **괄호가 없습니다.** 순서를 바꾸고 싶으면 중간 결과를 변수에 담으세요.
- **나누기와 나머지는 C 언어와 같습니다.** 몫은 0 쪽으로 버리고(−7 / 2 = −3), 나머지의 부호는 왼쪽 수를 따릅니다(−7 % 2 = −1). 0으로 나누면 에러입니다.
- **띄어쓰기에 주의하세요.** `우라라 우라라`(곱하기, 4)와 `우라라우라라`(나누기, 1)는 다릅니다. 헷갈리면 `--tokens`로 렉서가 어떻게 잘랐는지 확인할 수 있습니다.

```
$ usagi --tokens 파일.usagi
Token(kind='NUMBER', value=2, line=2)
Token(kind='DIVIDE', value=None, line=2)
Token(kind='NUMBER', value=2, line=2)
```

### 글자 출력

`루루루루루`는 계산한 값을 유니코드 번호로 보고 그 글자를 출력합니다.
예를 들어 `H`는 72 = 8 × 9이므로 `루루루루루 우라라라라라라라라 우라라라라라라라라라`입니다.
줄을 바꾸려면 줄바꿈 문자(10 = 2 × 5)를 출력합니다.

### 우사기어에 대해

"우사기어"는 공식 명칭이 아니라 팬들이 붙인 이름이며, 단어별 뜻도 공식 정의가 없고 팬들의 해석입니다. 키워드의 뜻은 [참고 자료](#참고-자료)의 팬 정리를 바탕으로 단어의 뜻과 어울리는 기능에 키워드를 배정했습니다.

## 예제

`examples/` 폴더에 단계별로 나뉘어 있습니다 (`step1/`, `step2/` …). 각 예제의 기대 출력은 같은 이름의 `.out` 파일, 입력은 `.in` 파일입니다.

| 파일 | 내용 | 출력 |
| --- | --- | --- |
| [hi.usagi](examples/step1/hi.usagi) | 글자 출력 | `Hi` |
| [numbers.usagi](examples/step1/numbers.usagi) | 숫자 출력, 곱하기, 음수, 0, 줄바꿈 없는 출력 | `6` `-3` `0` `12` |
| [hangul.usagi](examples/step1/hangul.usagi) | 한글 출력 (가 = 44032 = 32 × 32 × 43) | `가` |
| [variables.usagi](examples/step2/variables.usagi) | 변수, 대입, 사칙연산, 계산 순서 | `9` `5` `14` `3` `1` `7` `8` |
| [calculator.usagi](examples/step2/calculator.usagi) | 정수 두 개를 입력받아 사칙연산 | 입력 `17` `5` → `22` `12` `85` `3` `2` |
| [usagi.usagi](examples/step2/usagi.usagi) | 한글 조합 공식으로 "우사기" 출력 | `우사기` |

```
usagi examples/step1/numbers.usagi
```

입력을 받는 예제는 직접 키보드로 입력하거나, `.in` 파일을 넣어 줄 수 있습니다.

```
usagi examples/step2/calculator.usagi < examples/step2/calculator.in
```

## 구현 구조

```
소스 코드 → [렉서] → 토큰 목록 → [파서] → AST → [인터프리터] → 실행 결과
```

| 파일 | 역할 |
| --- | --- |
| `usagi/keywords.py` | 키워드 표. 모든 키워드 철자는 이 파일에만 있다 |
| `usagi/lexer.py` | 소스 코드를 토큰으로 자른다. NFC 정규화, 비슷한 기호 통일, 주석·빈 줄 제거 |
| `usagi/nodes.py` | AST 노드 정의 |
| `usagi/parser.py` | 재귀 하강 파서. 토큰 목록으로 AST를 만든다 |
| `usagi/interpreter.py` | AST를 따라가며 실행한다 |
| `usagi/environment.py` | 변수 저장소. 변수 번호 → 값 (나중에 가상 메모리로 바꿀 자리) |
| `usagi/errors.py` | 우사기랭 에러 (`UsagiError`) |
| `usagi/cli.py` | `usagi` 명령. 파일 읽기 → 렉서 → 파서 → 인터프리터, 에러를 `하아?`로 출력 |

예를 들어 `야하 우라라 우라라라`는 이렇게 바뀝니다.

```
토큰:  [PRINT] [NUMBER 2] [NUMBER 3] [NEWLINE]

AST:   Print
       └─ Multiply
          ├─ Number(2)
          └─ Number(3)

실행:  2 × 3 = 6 → "6" 출력
```

## 개발

```
git clone https://github.com/gksruf22/usagi-lang.git
cd usagi-lang
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
pytest
```

| 테스트 파일 | 확인하는 것 |
| --- | --- |
| `tests/test_lexer.py` | 키워드, 정수, 주석, 공백, 정규화, 렉서 에러, 파일 읽기 |
| `tests/test_parser.py` | AST 구조, 곱하기 묶는 순서, 문법 에러와 줄 번호 |
| `tests/test_interpreter.py` | 숫자·글자 출력, 변수, 사칙연산(음수 나누기 포함), 정수 입력, 실행 에러 |
| `tests/test_cli.py` | 실제 `python -m usagi` 실행, `하아?` 에러, 옵션 |
| `tests/test_examples.py` | `examples/`의 모든 예제 출력이 `.out`과 같은지 (`.in`이 있으면 입력으로 넣음) |

변경 내역은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
